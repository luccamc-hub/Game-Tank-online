* Online Tank Game (Web)

This is a browser-based multiplayer tank game where players control tanks on a battlefield. The objective is to eliminate opponents, dodge incoming attacks, and survive as long as possible.

---

* Features
* Real-time tank controls
* Online multiplayer mode
* Shooting and collision system
* Interactive map
* Basic scoring system
* Smooth browser gameplay

---

* Technologies Used
* HTML5
* CSS3
* JavaScript
* (Optional) Node.js for backend
* (Optional) WebSockets for real-time communication

---

* Getting Started

* 1. Clone the repository

https://github.com/luccamc-hub/Game-Tank-online

* 2. Navigate to the project folder

Game Tank online

* 3. Run the game
     You can simply open the index.html file in your browser:


open -> index.html


Or use an extension like Live Server in VS Code.

---

* Running with a Server  


* Install dependencies:

https://nodejs.org/en/download

* Start the server:


Open terminal and write "node server.js"


Then open:
http://localhost:3000 (using ctrl + left mouse button)

---

* How to Play
* W, A, S, D → Move the tank
* Spacebar → Shoot
* Goal → Destroy your enemy and survive
